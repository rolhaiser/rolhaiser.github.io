Problema 6: Metodos de integracion


Regla de trapecio

$\int_a^b f(x)\: dx \approx \frac{b-a}{2}\: [f(a)+f(b)]$

Esto es el area de un rectangulito nomas. $b-a = \Delta x$

In [23]:
import numpy as np
def f(x): #ejemplo de funcion a integrar
    return np.exp(-x**2)


def trapecio(fn,a,b): #area de un rectangulo
    return (b-a)/2 * ( fn(a)+fn(b) )

def integral(fn,a,b,metodo=trapecio,n=20): #area total con n rectangulos
    #metodo es una funcion
    area = 0 #acumulador
    dx = (b-a)/n #base de cada rectangulo
    for i in range(n):
        area += metodo(fn,a,a+dx)
        a += dx
    return area

print("integral con trapecio:",integral(f,0,1,metodo=trapecio))

integral con trapecio: 0.7466708369398735

Regla de simpson

$\int_a^b f(x)\: dx \approx \frac{b-a}{6}\: [f(a)+4.\:f(\frac{a+b}{2})+f(b)]$

In [24]:
def simpson(fn,a,b):
    return (b-a)/6 * ( fn(a)+  4*fn( (a+b)/2 )  +fn(b) )

print("integral con simpson:",integral(f,0,1,metodo=simpson))

integral con simpson: 0.7468241360053479
