Unidad 7: Ajuste curvas. Raices (pag 9):

Para ajustar los datos a una funcion lineal de la forma

$y(x) = a_0 + a_1\: x$

hay que determinar estos coeficientes de la sig forma:

$a_1= \frac{\sum_i \: (x_i-\bar{x})\: y_i}{\sum_i (x_i - \bar{x})\: x_i}\: ; \qquad \qquad a_0 = \bar{y}- a_1\: \bar{x}$

donde $\bar{x}$ es el promedio de todos los datos de x.


  1. Desarrollo de la funcion.

import numpy as np
def regrecion_lineal(xdatos,ydatos):
    n = len(xdatos) # = len(ydatos), n:cantidad de pares ordenados
    xprom = np.sum(xdatos)/n
    yprom = np.sum(ydatos)/n
    a1 = np.sum( (xdatos - xprom)*ydatos ) / np.sum(  (xdatos-xprom)*xdatos  )
    a0 = yprom - a1*xprom
    return a1, a0 # pendiente y ordenada

Problema 4: Determine los parametros $a$ y $b$ tal que satisface $f(x)=a\: e^{bx}$ ajustan los datos atraves de cuadrados minimos. Use la funcion np.polyfit(Lx,Ly,grado).

Donde "Lx" es la lista de datos de x, y "grado" es el tamaño del polinomio a usar.


Como $e^x$ no es una funcion polinomica, no podemos usar simplemente el polyfit. La estrategia es intentar linealizarla para poder usar ese comando, y despues despejar a y b.

$y = a.e^{bx} \implies \ln{(y)} = \ln{(a.e^{bx})}= \ln(a)+\ln(e^{bx}) = \ln{(a)}+bx$

Al tomar la regresion lineal de $x$ vs $\ln{y}$,

la pendiente es $b$, y la ordenada al origen es $\ln{a}$

En python,

  • El logaritmo natural es np.log(y)
  • El logaritmo base 10 es np.log10(y)

*Unidad 7: Ajuste curvas. Raices (pag 13):* Metodo de Biseccion

Queremos encontrar la raiz de una funcion $f(x)$. Esto es, encontrar el $x_s$ que satisface que $f(x_s) = 0$.

Al graficar la funcion, podemos estar seguros que dentro de un intervalo $(a,b)$ hay un valor $x_s$ (o varios) que anulan la fn. O tambien podemos confiar que hay uno.

Debe ocurrir que la funcion evaluada en los extremos sean de signo contrario.

$f(a).f(b)<0$

Revisamos el signo del punto medio, y ese va a ser nuestro nuevo extremo, remplazando al que tenia el mismo signo.

Repetimos este proceso N veces hasta que la longitud del intervalo $(b-a)$ sea muy pequeño. Este intervalo sera nuestro error.

En este problema nuestra funcion sera $f(x)= 2x-\tan(x)$

La longitud del intervalo inicialmente es $L_0= b-a$

Luego de dividir el intervalo por la mitad $n$ veces es $L_n= \frac{b-a}{2^n}$

Si esa longitud luego de $n$ iteraciones es el error $err$, entonces podemos despejar $n$.

El nro de intervalos necesarios para obtener una precision $err$ es:

$L_n =\frac{b-a}{2^n} = err \implies n = \ln(\frac{b-a}{err})/\ln(2)$

import numpy as np
def f(x):
    return 2*x-np.tan(x)

error = 10**(-3) #precision

def biseccion(fn,a,b,error=10**-5):
    #a es el extremo inferior, y b el superior
    fa = fn(a)
    fb = fn(b)
    if abs(fa) <= error: return a #revisamos no estar ya en la raiz
    if abs(fb) <= error: return b
    if fb*fa > 0: return False #no se cumple el teorema de bolsano
    #n = np.log((b-a)/error)/np.log(2) #podemos usar esto para un for
    while (b-a)/2 > error: 
        xm = (b+a)/2
        if abs(fn(xm)) <= error: return xm
        if fn(xm)*fa <0: b = xm; fb =fn(xm)  #nuevo superior
        else: a= xm; fa = fn(xm) # : if fn(xm)*fb <0
    return (a+b)*0.5

a= 1 ; b=1.5
print("encontramos una raiz en:", biseccion(f,a,b,error))
print("el nro de iteraciones necesarias para eso eran: ", int(np.log((b-a)/error)/np.log(2)))

Problema 7: Metodo de Newton-Raphson y de biseccion-secante.


El metodo Newton-Raphson es el que usan las calculadoras cientificas para resolver ecuaciones.

Tiene la ventaja de que es el que calcula mas rapido de todos, pero no siempre funciona.

Este metodo tiene que calcular derivadas (sin derivar a mano), y tambien necesita que tiremos un numero que creamos que esta cerca de la raiz, usualmente $x_0=0$. Si la derivada cambia muy rapido, o elegimos un valor inicial inadecuado, este metodo puede no llegar nunca a la solucion.

El algoritmo es el siguiente:

$x_{nuevo} = x_{0} - \frac{f(x_0)}{f'(x_0)}$

Con un error de err = abs( x_nuevo-x_0 )

import numpy as np

def derivada(fn,x,h=0.001): #derivada por definicion
    return (fn(x+h)-fn(x))/h

def newton_rapshon(fn,x,error=0.001): #la derivada no queda como argumento pq ya esta def generalmente
    while abs(fn(x))>error:
        x = x - fn(x)/derivada(fn,x) #calculamos el siguiente valor a evaluar
    return x

def biseccion_secante(fn,a,b,error=10**-5):
    #a es el extremo inferior, y b el superior
    fa = fn(a);fb = fn(b) #nueva forma de definir variables
    if fa == 0: return a
    if fb == 0: return b
    if fb*fa > 0: return False #no se cumple el teorema de bolsano
    #xm es el pto que anula la recta secante que pasa entre fa y fb
    xm = a -fa/((fb-fa)/(b-a))
    while abs(fn(xm)) > error:
        xm = a -fa/((fb-fa)/(b-a))
        if fn(xm)*fa <0: b = xm; fb =fn(xm)  #nuevo superior
        else: a= xm; fa = fn(xm)
    return xm
