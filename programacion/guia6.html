Una matriz cuadrada $\mathbb{M}$ es simetrica si es igual a su transpuesta: $\mathbb{M}= \mathbb{M}^T$

Con numpy, se puede calcular la transpuesta con np.transpose(M) o M.transpose()

(b) Realizar una funcion que verifique si una matriz de dimension n es ortogonal, es decir si el producto de ella por su traspuesta es la matriz identidad.

Una matriz cuadrada $\mathbb{M}$ es ortogonal si cumple que $\mathbb{M} . \mathbb{M}^T = \mathbb{I}$

np.shape(M) da como resultado una tupla con tamaño de la lista, por ejemplo (3,3)

np.eye(n) crea la matriz identidad de tamaño $n\times n$

El producto matricial de algebra en python es asi: M1 @ M2

otra alternativa es escribiendo np.matmul(M1,M2)

In [9]:
import numpy as np
def ortogonal(M): #¿ M. M^T = identidad(nxn) ?
    return np.all(   M @ np.transpose(M)  ==  np.eye(np.shape(M)[0])   )

M_o = np.array([ [0,-1], [1,0] ]) #matriz ortogonal
M_no = np.array([ [1,2], [-3,-4] ]) #matriz no ortogonal

print("es M_o ortogonal?:", ortogonal(M_o))
print("es M_no ortogonal?:", ortogonal(M_no))

es M_o ortogonal?: True
es M_no ortogonal?: False

(c) Realizar una funcion que determine la norma de Frobenius (raiz cuadrada de la suma de los cuadrados de las componentes i.e. $||\mathbb{A}|| = \sqrt{\sum_i \sum_j A_{ij}^2}$ de una matriz dada.

Es decir, sumamos todos los elementos de la matriz al cuadrado y a eso le aplicamos la raiz.

Al tomar M*M esto no es el producto matricial de algebra, esto eleva al cuadrado cada uno de sus elementos.

In [10]:
def frobenius(M): #norma de una matriz
    return (  np.sum( M*M )   )**0.5

Problema 5: Se puede rotar un punto alrededor del eje $z$ mediante la siguiente transformacion

\begin{equation*} \vec{r} \:`= \begin{pmatrix} \cos \theta & -\sin \theta & 0 \\ \sin \theta & \cos \theta& 0\\ 0 & 0 & 1 \end{pmatrix} \cdot \begin{pmatrix} x \\ y \\ z \end{pmatrix} \end{equation*}

Donde $\vec{r}$ $'$ es el vector (matriz columna) cuyas componentes rotadas son $(x',y',z')$. Implementar un programa que dado un vector $\vec{r}$ con sus componentes en el espacio, de obtenga el vector rotado alrededor del eje $z$ en un angulo $\theta$.

Por otro lado, la traslacion de la posicion en la direccion $z$ se puede implementar como:

\begin{equation*} \vec{r} \:`= \begin{pmatrix} x \\ y \\ z \end{pmatrix} + \begin{pmatrix} 0 \\ 0 \\ D \end{pmatrix} \end{equation*}

Asumiendo que $\theta = \omega t$ (movimiento circular uniforme) y que $D= V.t$ (MRU) implementar un programa que obtenga la trayectoria de la particula en el espacio.

In [12]:
import numpy as np

def rotar_z(r,ang): #queremos rotar un vector r, alrededor del eje z un angulo ang
    Mr = np.array([[np.cos(ang),-np.sin(ang),0],[np.sin(ang),np.cos(ang),0],[0,0,1]]) #matriz de rotacion
    return Mr @ r #vector rotado

def traslacion_z(r,D):
    return r+np.array([0,0,D])

def MCU(t,w): #movimiento circular uniforme
    return w*t # = angulo(t)

def MRU(t,v): #movimiento rectilineo uniforme
    return v*t # = posicionD
